# Archive

Frozen records: the deep reviews, probes, handoffs, findings dumps and the
completed rows of the opportunity backlog that drove development through
2026-08/2026-09. They stay here because the code cites them — several refusals
and deliberate non-decisions (`perf-harness`, the native a11y census, the B-15
caches) name a file in this directory as the evidence behind them.

Rules:

- **Records are immutable.** Do not rewrite an archived file; if a decision is
  revisited, write a new dated file and link both ways.
- **The live plan is `docs/reviews/backlog.md`** — open items only. Completed
  rows live in `backlog-completed-2026-10.md` with their PR records.
- These files are history, not documentation: they describe behaviour as
  measured at the time, some of which has since changed. For how the tool
  works now, read the top-level `docs/`.
